# Re-exported generics

[`as_tibble()`](https://tibble.tidyverse.org/reference/as_tibble.html)
is re-exported from the tibble package and
[`autoplot()`](https://ggplot2.tidyverse.org/reference/autoplot.html)
from ggplot2 so that `banditlab` results can be converted and plotted
without attaching those packages explicitly.
